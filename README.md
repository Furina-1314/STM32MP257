# Salacia
硬设大赛代码仓库
## 使用
1. 可以先在VS Code等等上克隆该仓库，之后再开发。
2. 对于不同功能的代码，分置于不同文件夹下，建好文件夹后再向仓库推送。
3. 设计图纸等资料，也可归类后推送至仓库。

## 下一步需注意
1. 目前产品设计尚有冲突之处。计划未来删去终端的SSH功能，采用TCP/UDP与开发板通信。

Socket模块可以考虑由目前的SSH模块改造。
   
   计划的通信：

   |通信协议|通信内容|备注|
   |-------|------- |---|
   |TCP|舵机、推进器指令发送|强调完整性|
   |UDP|推流、传感器数据|强调即时性|

   通信数据包的格式需要进一步协商。

2. 等待开发板端的进一步开发。等待开发板端API的构建，依据其返回的结构体架构做read相关函数的修改。

3. 摄像头的推流存在1-2s延迟。具体原因需要进一步排查，优化的可行性待进一步研究。

4. 终端的GUI尚待优化。需要为终端选取图标。

## 网络
目前DHCP的静态租约：
|设备|IP|
|---|---|
|Salacia|192.168.1.120|
|Fzl|192.168.1.100|
|Xuan|192.168.1.102|

子网掩码255.255.255.0，网关192.168.1.1。

开发板为静态IP，主机的IP基于MAC地址静态分配，均位于DHCP分配池中。若未来分配出现问题，可使用静态IP上网。若如此，注意开发板的IP配置。
